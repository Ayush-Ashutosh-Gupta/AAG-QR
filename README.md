\# AAG QR



AAG QR is a private QR code toolkit built for personal use. It focuses on speed, offline capability, and practical features without ads or forced accounts.



\## Features



\- Generate QR codes for text, URLs, Wi-Fi, contacts, calendar events, locations, and documents

\- Custom styling (colors, error correction, logo options)

\- Built-in QR scanner

\- Dynamic QR support

\- Temporary document hosting (24-hour links)

\- Local history and basic analytics

\- Offline-first design



\## Document QR



Upload a file to receive a temporary public link (valid for 24 hours), then encode that link into a QR code for short-term sharing.



\## Tech Stack



\- Kotlin

\- Jetpack Compose

\- CameraX

\- Room Database



\## Purpose



Built as a personal utility. Structured enough to demonstrate Android development skills.
